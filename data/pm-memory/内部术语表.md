# bagent 项目内部术语表

> 判断标准：新来的实习生只看项目资料，不问任何人，能否理解该词在本公司、本项目里的含义和边界。

| 术语 | 定义 | 使用场景 | 备注 |
|------|------|----------|------|
| Lily | 猎聘 AI 招聘助手产品的名称，即本项目（bagent）的对外产品名 | 产品文档、用户界面 | 项目内部代号 bagent，对外称 Lily |
| Hermes | 对话系统的底层平台，负责对话创建、消息管理等 | 对话创建、职位绑定 | 对话与职位的关系是"挂靠"而非强绑定 |
| 对话 | Lily 中用户与 AI 的一次会话单元，可挂靠一个职位作为分组依据 | 对话管理、职位关联 | 在 Hermes 中，职位信息仅作为上下文存在 |
| 在招职位 | 企业版中状态为"招聘中"的职位，是新手引导中用户选择的对象 | 新手引导、职位选择 | 由企业版职位管理模块提供数据 |
| 企业版 | 猎聘企业端产品，HR 用户使用的招聘管理平台 | 整体产品架构 | Lily 作为企业版内的 AI 功能模块 |
| 预置上下文 | 对话创建时自动带入的初始语句，用于告诉 AI 用户的意图 | 对话创建 | 例如"我现在想针对这个职位帮你进行寻访" |
| 新手引导 | 首次进入 Lily 时的引导流程，帮助用户理解产品并快速开始使用 | 新手引导功能 | 三步：介绍功能 → 选择职位 → 创建对话 |
| Agent | AI 智能体，在本项目中指 Lily 背后的大模型能力 | 技术讨论、产品架构 | 用户视角是"AI 助手"，不感知 Agent 概念 |
| Skill | Agent 的能力模块，每个 Skill 对应一个具体功能（如职位访谈、简历搜索） | Skill 流程、功能开发 | 用户不直接感知 Skill，通过对话间接触发 |
| 导流 | 将 Lily 用户引导至猎聘商业产品的行为 | 导流埋点、商业转化 | 产品核心目标之一 |
| 商业产品 | 猎聘的付费招聘服务（如主动联系、意向候选人等） | 商业转化流程 | Lily 的最终目标是引导 HR 使用商业产品 |
| 曝光（工程项目） | 上线工程项目代号之一，即「邀约」功能；含新 prompt 和记忆功能，6/15 灰度上线时最先灰度 | 上线灰度策略、上线排期 | 6/15 首次在会议纪要出现 |
| 鲁班（工程项目） | 上线工程项目代号之一；6/16 全量上线（新增功能，无风险） | 上线灰度策略 | 6/15 首次出现 |
| 朱雀（工程项目） | 上线工程项目代号之一；6/16 全量上线（新增功能，无风险） | 上线灰度策略 | 6/15 首次出现 |
| 夸父（工程项目） | 上线工程项目代号之一；6/16 全量上线（新增功能，无风险） | 上线灰度策略 | 6/15 首次出现 |
| BEF（工程项目） | 上线工程项目代号之一，即「菜单项目」；6/15 确认本期不上线，因菜单在其中、上线会暴露入口 | 上线灰度策略、入口暴露风险 | 6/15 首次出现 |
| IDP | 内部消息/事件投递队列机制；上线后需检查 IDP 接收目录并逐项确认开启状态（开启操作须在上线完成后执行） | 上线 SOP、上线风险检查 | 6/15 首次出现；具体技术含义待补全 |
| 后羿 | 猎聘承载简历匹配（预选/模选）与意向人选服务的系统 | 匹配系统、技术对接 | 含后羿5.0匹配一期/流程调整/端到端匹配/自动放宽等模块，老肖（肖金华）负责。见 [[20260708 业务术语调研-猎聘招聘业务]] |
| 预选 | 猎聘简历筛选的初筛环节，基于结构化字段（地点/薪酬/行业/经验/学历）+向量化索引，从海量简历库广撒网圈出符合基本条件的人选 | 简历筛选、智能邀约 | 位于模选之前，召回量大（数千份）、速度快、成本极低，结果分高/中/低三档。见 [[20260708 业务术语调研-猎聘招聘业务]] |
| 模选 | 猎聘简历筛选的精筛环节，用大模型将 JD+访谈内容拆成匹配维度，逐条核对简历契合度并生成匹配理由；位于预选之后、确认意向之前 | 意向人选筛选、AI猎头交付 | 含套壳（规则筛选）→精筛→排序（高/中/低/不匹配）三步；分需求加工/需求放宽两阶段；多模式（单维度/端到端/端到端+单维度）。专业版不用访谈，青春版/pro 用访谈。见 [[20260708 业务术语调研-猎聘招聘业务]] |
| JD+ | 广义 JD，含 JD + JD在线访谈 + JD电话访谈 + 推荐简历后反馈信息，描述更全面的招聘需求 | 自动放宽策略、职位记忆(JD+2.0)、新用户需求优化 | 支撑自动放宽提升召回；作为职位记忆核心打通职位发布/访谈/意向人选/推荐/搜索多场景。见 [[20260708 业务术语调研-猎聘招聘业务]] |
| 意向人选 | 猎聘商业产品，顾问交付、HR等结果，仅看最终有意向简历，下载简历时付费 | 商业转化、Lily导流目标 | Lily 候选人少时推荐的产品之一；与AI寻访形成“卖结果 vs 卖沟通”对比。见 [[20260708 业务术语调研-猎聘招聘业务]] |
| AI寻访 | 猎聘招聘工具，HR主导、AI辅助，对话完成「拆条件→找人→联系人选」全流程，全程可见可汇报 | 招聘工具、商业化 | 卖沟通预付费（20-50元/人，48h未反馈可退）；与意向人选区别：HR主导、全流程可见、沟通时付费；底层靠统一访谈+统一记忆。2026/2/2企业版全量上线。见 [[20260708 业务术语调研-猎聘招聘业务]] |
