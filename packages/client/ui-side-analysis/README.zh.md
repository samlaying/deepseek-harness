# @deepseek-ai/dsh-client-ui-side-analysis

[English](README.md) | 中文

对话旁听分析面板插件：静默订阅主对话的完整交互生命周期，自动推断用户意图、满意度与偏好特征，并在右侧以响应式收折面板呈现分析记录与提供用户交互校验。

## 功能特性

- **静默旁听**：不破坏或修改主对话 DOM，无侵入式监听对话流。
- **自动逐轮分析**：每一轮 Q&A 自动生成结构化的 `AnalysisRecord`，包含意图分类、首 token 耗时、token 数量、多信号加权满意度评级（1-5 星）与推断依据。
- **偏好画像推断**：持续提取并累积用户偏好（回答长度偏好、技术深度、主要语言、代码风格、语气偏好以及高频话题）。
- **右侧停靠面板**：挂载在 `shell.overlay` 槽位，默认 48px 收折窄条（展示平均星级与未校验低满意度红点提醒），点击可展开 360px 完整分析卡片。
- **用户主动校验**：支持 1-5 星手动评分、准/不准快速标记及展开备注输入框，使用 `localStorage` + `IndexedDB` 双写持久化。
- **热更新与 HMR 兼容**：遵循 DSH 客户端插件规范与 `data-plugin="side-analysis-panel"` 样式清理协议。

## 模型体验

纯客户端展示与旁听插件，不修改模型上下文与工具定义。

#### KV Cache 影响

无影响。
