# 产品机制与难缠用户交互设计 (Mechanism & Interaction)

## 核心原则
1. **产品机制推导**：
   - 用户在什么状态下需要它？
   - 系统在什么状态下触发它？
   - 什么算完成？
2. **三句话评审口径**：
   - 用户看到什么 (界面/文案/视觉状态)
   - 用户能做什么 (可操作/不可操作/跳过)
   - 然后发生什么 (状态流转/持久化/反馈)
3. **难缠用户极端兜底**：
   - 默认用户最没耐心、网络随时断开、连续快速点击手抖。
   - 失败默认保留草稿和输入内容。
   - 空态、无权限、超时、无匹配结果均必须有兜底动作与恢复路径。
